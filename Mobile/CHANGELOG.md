# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of Kos Terpadu mobile app
- Authentication system (login, register, logout)
- Role-based access control (admin & penghuni)
- Kamar management (CRUD operations)
- Kamar list with filter by status
- Kamar detail view with facilities
- Penghuni management
- Pembayaran system
- Tagihan management
- Keluhan system with realtime updates (Firebase Firestore)
- Upload foto keluhan (Firebase Storage)
- Realtime chat between admin and penghuni
- Chat room with message history
- Notification system
- Custom reusable widgets (Button, TextField, Cards)
- Form validation
- Error handling
- Loading states
- Empty states
- Responsive UI design
- Modern minimalist UI
- Named routing
- Environment configuration
- HTTP service wrapper
- Firebase service wrapper
- Storage service wrapper
- Helper functions
- Validators
- App theme configuration
- MVC + Service Layer architecture
- Provider state management
- Complete documentation

### Security
- JWT token authentication
- Password hashing
- Secure local storage
- Authorization checks
- Input validation
- SQL injection prevention

### Documentation
- README.md with complete guide
- ARCHITECTURE.md with detailed explanation
- API_DOCUMENTATION.md for backend API
- SETUP_GUIDE.md for installation
- ERD_DIAGRAM.md for database schema
- PROJECT_SUMMARY.md for overview
- Code comments in Indonesian
